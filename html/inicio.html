Proyecto VioGén

Presentación del proyecto

Esta aplicación web tiene como objetivo gestionar información relacionada con incidencias de violencia de género mediante formularios desarrollados en PHP.

El proyecto funciona como un simulador académico de seguimiento de casos: permite registrar y consultar víctimas, agresores e incidencias, recoger indicadores orientativos de riesgo y generar un informe final con la información del caso.

El alcance del sistema está limitado a la práctica de programación en PHP. La valoración final se basa en una regla didáctica propia y no reproduce el algoritmo oficial del sistema VioGén ni sustituye una valoración profesional.

Este proyecto tiene una finalidad exclusivamente académica. No reproduce el sistema oficial VioGén ni sustituye una valoración profesional. Se utilizarán únicamente datos ficticios.
